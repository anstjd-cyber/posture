# posture — 거북목 측정 결과 페이지

디지털 부스에서 운영하는 **거북목 측정 체험**의 결과 페이지입니다.
부스 화면에 뜬 QR을 스캔하면 체험자의 휴대폰에서 이 페이지가 열립니다.

👉 **https://anstjd-cyber.github.io/posture/result/**

## 어떻게 동작하나요

부스의 측정 앱은 노트북에서 로컬로 실행되고, 측정이 끝나면 점수를 **주소에 담아** QR을 만듭니다.

```
https://anstjd-cyber.github.io/posture/result/#s=72&g=B&a=74.3&b=96
                                                 │    │    │      └ 어깨 균형 0~100
                                                 │    │    └────── 목 각도 (도)
                                                 │    └─────────── 등급 A/B/C/D
                                                 └────────────────── 점수 0~100
```

- **서버도 데이터베이스도 없습니다.** 점수가 주소 안에 그대로 들어있습니다.
- **수집하는 개인정보가 없습니다.** 로그인도, 입력도, 추적도 없습니다.
- 측정 영상은 부스 노트북 안에서만 처리되며 저장되거나 전송되지 않습니다.
- 체험자는 자기 휴대폰 데이터로 열기 때문에 행사장 와이파이와 무관하게 동작합니다.

파라미터 없이 그냥 열면 점수 영역이 빠지고 **스트레칭 가이드만** 보입니다.
포스터에 "스트레칭 가이드" QR을 따로 붙일 때 그대로 쓰면 됩니다.

## 페이지에 들어있는 것

- 점수 · 등급 · 등급별 설명
- 측정된 각도를 그대로 그린 **자세 그림** (점선 = 머리가 어깨 바로 위인 기준 위치)
- 등급별 **맞춤 스트레칭** — A 2개 / B 3개 / C·D 4개, 동작마다 유지 시간 타이머 포함
- 작업 환경 체크리스트
- 거북목 설명, 면책 문구

밝은 테마와 어두운 테마를 모두 지원하며 휴대폰 설정을 따릅니다.

## 테스트 주소

```
.../result/#s=88&g=A&a=82.4&b=96    양호
.../result/#s=58&g=B&a=72.0&b=83    주의
.../result/#s=30&g=C&a=61.4&b=55    거북목 의심
.../result/#s=8&g=D&a=53.1&b=41     거북목 심함
.../result/                         파라미터 없음 (가이드만)
```

## 고치려면

`result/index.html` 한 파일에 전부 들어있습니다. 외부 라이브러리를 쓰지 않습니다.

| 고치고 싶은 것 | 찾을 위치 |
|---|---|
| 등급별 설명 문구 | `const GRADES` |
| 등급별 처방 | `const PLANS` |
| 스트레칭 동작·설명·시간 | `const EXERCISES` |
| 환경 체크리스트 | `const CHECKS` |
| 색상 | 맨 위 `:root` |
